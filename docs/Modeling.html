Introduction

The data explored in this analysis comes from the CDC’s BRFSS 2015 survey. The target variable for analysis is the Diabetes_binary variable, which has two classes: no diabetes and prediabetes/diabetes. There are 21 predictor variables in the dataset that may be included in the subsequent models. The dataset is unbalanced, meaning there are more cases in which the survey respondent had no diabetes than cases in which the respondent had prediabetes or diabetes. This is important for modeling because we want to ensure that our model performs better than the majority class rate, which is the rate of the largest class in the dataset. In this case, the largest class is the no diabetes class. The majority class rate is 86.07 percent, which is important to note if we were using accuracy as our metric. However, in this analysis, we will be using log loss as the evaluation metric, so the majority class rate will not be our primary concern. In addition to using log loss as the metric for determining the best models, the modeling process will include 5 fold cross-validation and will consider logistic regression, classification trees, and random forest models.

Utilizing the transformed data from the EDA process, it is important to split the data into a training and test set for utilization in modeling. By performing this split, it helps prevent over fitting as the goal of modeling is to predict well on unseen data. By saving 30% of our data set to utilize in analyzing the models, it will help determine the optimal model from this modeling process.

Logistic Regression Models

The first model that will be considered for modeling this Diabetes data set is the logistic regression model. A logistic regression model is a type of parametric model that requires the response variable to be binary/two classes. This is why logistic regression is useful for this data as our response variable of Diabetes_binary is two classes: No_Diabetes and Prediabetes_or_Diabetes. This logistic regression model is predicting the probability given the predictors that a person belongs to the class of Prediabetes_or_Diabetes.

In this section, we will evaluate three candidate logistic regression models using 5 fold cross validation on the training subset of the Diabetes data set. Utilizing log loss as the metric, we will determine which of the three models performs the best and select that model as the best logistic model of the three that were analyzed. The three models are as follows:

Logistic Regression Model 1:

\[ P(Y=Prediabetes or Diabetes)=\frac{e^{\beta_0+\beta_1(BMI)}}{1+e^{\beta_0+\beta_1(BMI)}} \]

Logistic Regression Model 2:

\[ P(Y=Prediabetes or Diabetes)=\frac{e^{\beta_0+\beta_1(BMI)+\beta_2(HvyAlcoholConsump)+\beta_3(Income)}}{1+e^{\beta_0+\beta_1(BMI)+\beta_2(HvyAlcoholConsump)+\beta_3(Income)}} \]

Logistic Regression Model 3:

Similar equation to models 1 and 2, however, every predictor variable (21 of them) is included.

Classification Tree

The next model that will be considered for modeling this Diabetes data set is the classification tree model. A classification tree model is a type of nonparametric model that attempts to predict the response class given a set of predictor values. This is why classification trees are useful for this data as our response variable of Diabetes_binary is two classes: No_Diabetes and Prediabetes_or_Diabetes. Classification trees continue creating subsets of the response space based on the predictors until some sort of stopping criteria is met. In this case, I have set the minimum allowed observations to be in a final subseted space to be 5 survey respondents.

In this section, we will determine the optimal complexity parameter (cp) using 5 fold cross validation on the training subset of the Diabetes data set. Utilizing cross validation error (xerror) as the metric, we will determine the optimal cp. The cp parameter helps prevent overfitting be reducing the complexity of the classification tree. The allowed parameters for the classification tree will be all 21 predictors in the data set.

#Set a seed for reproducible results
set.seed(8675309)

#Run the classification tree to determine optimal cp using 5 fold cv
diabetes_rpart <- rpart(Diabetes_binary~.,
                      data=train,
                      method="class",
                      parms = list(split="information"),
                      control=rpart.control(xval=5,
                                            minbucket=5,
                                            cp=0))
#Optimal cp is cp=0.0004113784
as.data.frame(diabetes_rpart$cptable[1:15,c(1,2,4)])

rpart.plot(tuned_tree)
